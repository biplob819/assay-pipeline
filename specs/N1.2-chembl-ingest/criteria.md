# N1.2 acceptance criteria

**CHM-01** Paging requests `activity.json` with the configured target, activity type, `order_by=activity_id` and the configured page size, advancing the offset until `total_count` records are cached; on the recorded fixture it caches exactly the 15 records over 3 pages in activity-id order.
**CHM-02** Every cached activity record carries the fields later stages need (listed in the spec), checked on the recorded fixture; a page whose records name another target or activity type stops the ingest with an error naming the offset.
**CHM-03** The release is read from `status.json` before any activity page; bodies are stored gzip with mtime 0 under their request key, each indexed by one valid `RawResponse` line naming the release; reading a body whose bytes no longer match `body_sha256` raises an error.
**CHM-04** A rerun after an interruption resumes and re-fetches no cached page; a rerun on a complete cache makes no page requests and writes nothing; a page is validated before it is cached, so a bad page never poisons a later run; a changed live release while an older release is incomplete (with or without a cursor), a cache built for another target, activity type or page size, overlapping or reordered pages, or a `total_count` change mid-run each stop with an error naming the cause and a remedy that works; `--new-release` abandons the incomplete older release and later runs need no flag; a second concurrent writer is refused.
**CHM-05** Transport errors, 429 and every 5xx are retried with capped exponential backoff and jitter (honouring `Retry-After` up to the cap) up to 6 attempts, then fail the stage with nothing half-written; other 4xx, other HTTP errors and unparseable bodies are never retried and become errors naming the request's parameters; corrupt cache files are clean errors (CLI exit 2); the user agent names only the tool and its public homepage (D-27).
**CHM-06** The recorded fixture holds real ChEMBL responses with their licence attribution, every ingest test runs on it through a mock transport with sockets blocked, running the ingest twice into two empty caches gives byte-identical cache files, and a golden test pins the digest of that cache.
