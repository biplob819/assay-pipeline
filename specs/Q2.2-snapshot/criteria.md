# Q2.2 acceptance criteria

**SNP-01** The three Parquet files are written deterministically (explicit schemas, rows in §5.5 order, fixed row groups, zstd at a fixed level, dictionary encoding, no pandas or Arrow schema metadata), so two builds write identical bytes, and a snapshot reads back to the same validated rows.
**SNP-02** The manifest records the snapshot id, target, cache-derived creation time, source releases, raw-cache hash, rows by source, drops by reason, flags by rule, a file hash and a content hash for every file, tool versions, a code fingerprint and the planted flag; a tampered file is caught on read, and so is a consistent tamper, because every count is recomputed from the rows.
**SNP-03** The snapshot id is `YYYY-MM-DD.n` from the ChEMBL fetch date; the same build identity (cache, fetch time, config, ledger, libraries, planted rows, code) reuses it, anything else takes the next n, and no snapshot is ever replaced by different content or deleted when renamed.
**SNP-04** The rebuild gate is live: two clean builds from the recorded responses give byte-identical manifests, and the golden manifest from the recorded responses matches the stored one apart from the code fingerprint and tool versions.
**SNP-05** `DATA_CARD.md` reports sources, releases, yields per source, drops by reason, every rule with its count, cross-source compounds and the stated limits; `DATA_LICENSE.md` gives CC BY-SA 3.0 with ChEMBL attribution and every cleared depositor's terms.
**SNP-06** The publish path copies a verified snapshot's fixed files and refuses a manifest with `planted=true`, planted rows under `planted=false`, a manifest listing other files (no path traversal), a tampered snapshot, or a different snapshot under an existing id.
**SNP-07** Every stage writes a stage manifest of inputs, outputs, row counts, drops and tool versions; an up-to-date snapshot is skipped, and a changed input (including the cache's fetch time), code version, damaged output or damaged stage manifest is rebuilt; a failed build leaves no partial snapshot.
