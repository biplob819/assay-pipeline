# R6.1 acceptance criteria

**RMP-01** One page takes the snapshot to features to a training split, with leakage rules (scaffold and compound grouping, a time split once dates exist, cross-source duplicates once, a frozen test set) and what a scientist would add, using the real snapshot's numbers.
**RMP-02** The page names what would catch the planted stealth rows the QC rules miss: cross-assay consistency, literature checks and scientist review, with the stealth count matching the planted fixtures.
